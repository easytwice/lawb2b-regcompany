# LAW B2B — регистрация компаний в Китае и Гонконге

Проект двуязычного сайта [lawb2b.ru](https://lawb2b.ru/) на HTML, CSS, JavaScript и PHP.

## Состав проекта

- `lawb2b-landing/` — исходные файлы сайта, изображения, обработчик формы и настройки Apache. Инструкция по размещению — в `lawb2b-landing/README.md`.
- `lawb2b-landing.zip` — архив сайта для размещения на хостинге.
- `struktura.md` — структура и содержание лендинга.
- `privateconf.md` — исходный текст политики конфиденциальности.
- `FORM_TEST_REPORT.md`, `SECURITY_AUDIT.md` — результаты проверок.
- `output/imagegen/` — исходные изображения отзывов.
- `output/metrika-deploy/` — файлы, опубликованные на Timeweb 6 ноября 2026 года, и результаты проверки.
- `output/metrika-deploy-backup/` — резервные копии до публикации Метрики.
- `.playwright-cli/` — снимки страниц и скриншоты проверок интерфейса.

## Яндекс Метрика

Счётчик **114104949** подключён на главной странице и странице политики конфиденциальности. Включены Вебвизор, карта кликов, отслеживание ссылок и точный показатель отказов.

На действующем хостинге главная страница открывается из `index.htm`. В `output/metrika-deploy/` сохранены опубликованные версии `index.htm`, `index.html` и `privacy.html`; перед повторной публикацией следует учитывать порядок индексных файлов в настройках хостинга.

## Доступы

Пароли от хостинга не хранятся в репозитории. Локальный файл `account_hosting.txt` исключён через `.gitignore`.
